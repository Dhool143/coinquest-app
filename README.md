# CoinQuest App

CoinQuest is a personal finance and goal tracking mobile application designed to help users manage their savings goals and financial progress.

## Features
- User authentication
- Personal finance dashboard
- Savings goal tracking
- Transaction management
- User settings and preferences

## Technologies Used
- React Native
- Expo
- Supabase
- PostgreSQL
- GitHub

## Database Tables
- profiles
- goals
- transactions
- settings

## Project Goals
The goal of this project is to build a full-stack mobile application that demonstrates:
- relational database design
- API integration
- authentication
- CRUD operations
- frontend and backend connectivity

Currently in development.
